# Andymarcus Tap

## How do I install these formulae?

`brew install andymarcus/tap/<formula>`

Or `brew tap andymarcus/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "andymarcus/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
